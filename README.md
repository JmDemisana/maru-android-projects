# Maru Android Projects

Android apps for studying and watching anime.

## Maru Study

A local study dashboard for class schedules, homework reminders, and grades. View your timetable as a grid or list, and use the TUP Grade Solver to calculate grades and export PNG reports.

[Source](apps/maru-study) · [Download Maru Study 1.0.4](https://github.com/JmDemisana/maru-android-projects/releases/download/maru-study-v1.0.4/maru-study-1.0.4.apk)

## Nanami Anime

An anime player and AniList companion with Guest Mode, watch progress sync, Chromecast, and offline episode downloads. **2.1.1** is the first definitive release of the relaunched app.
