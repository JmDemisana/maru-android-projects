# Maru Android Projects (Monorepo)

Monorepo containing all Android applications for the Maru ecosystem, standardized on Gradle Version Catalogs and Kotlin 2.0.

## Apps

- **`apps/lastnotif`**: **LastNotif** — Smart band notification & live synced lyrics broadcaster (Last.fm & local media sessions).
- **`apps/marucast`**: **Marucast** — Low-latency LAN audio sender & now-playing broadcaster for the `/marucast` receiver.
- **`apps/tup-ers`**: **TUP-ERS** — TUP portal utility & scraper app.
- **`apps/nami-agent`**: **Nami Agent (Mobile)** — Android companion app with native push, applet hosting, and shared services (formerly `maru-mobile`).

## Shared Libraries

- **`libs/shared-ui`**: Common Jetpack Compose UI components.
- **`libs/shared-utils`**: Shared Kotlin utilities and helpers.
- **`libs/shared-network`**: Shared OkHttp wrappers and network models.

## Release Tags

- LastNotif: `lastnotif/vX.Y.Z`
- Marucast: `marucast/vX.Y.Z`
- TUP-ERS: `tup-ers/vX.Y.Z`
- Nami Agent (Mobile): `nami-agent/vX.Y.Z`
